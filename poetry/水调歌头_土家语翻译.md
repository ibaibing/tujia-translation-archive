# 苏轼《水调歌头·明月几时有》土家语翻译

**作者**：宋·苏轼  
**背景**：丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。苏轼当时在山东密州做官，和弟弟苏辙多年分离，中秋之夜望月饮酒写下这首词。既是咏月，也是抒发人生感慨，是中秋千古名篇。

## 第二层：解析（详解）

### 逐句词典依据（页码＝OCR 文件名−17）

#### **第1句**｜明月几时有？把酒问青天。
- **土家语 Ye拼音**：`sursur qixdux xief? ziif zav mef sevlir.`
- **逐词**：sursur（月亮）qixdux（什么时候）xief（有），ziif（酒）zav（拿/端）mef（天）sevlir（问）
- **词典依据**：
  - 月亮 → `[su²¹su²¹]` (S词典262页, p0279) → Ye: sursur
  - 什么时候 → `[ʨʰi⁵⁵tu⁵⁵]` (S词典344页, p0361) → Ye: qixdux（ʨʰ→q，55→x；tu⁵⁵→dux）
  - 有 → `[ɕiɛ³⁵]` (S词典27页, p0044) → Ye: xief（ɕ→x，iɛ→ie，35→f；跟"tʰai³⁵ 没有"相对）
  - 酒 → `[zɿ³⁵]` (S词典468页, p0485) → Ye: ziif（ɿ→ii，35→f）
  - 拿/把 → `[ʦa⁵³]` (S词典361页, p0378) → Ye: zav（②拿，用手抓住：ko³⁵ ʨiɛ³⁵ ʦʰu³⁵ sã⁵³ la⁵⁵ pʰa⁵⁵ ~ po²¹ la²¹. 他手里拿着一把伞；53→v）
  - 问 → `[sɤ⁵³li²¹]` (S词典272页, p0289) → Ye: sevlir（ɤ→e，53→v；li²¹→lir；B词典 亦作 sivhxer 第2086条）
  - 天 → `[mɤ³⁵]` (S词典166页, p0183) → Ye: mef（ɤ→e，35→f；B词典第1500条 mef=天空）

#### **第2句**｜不知天上宫阙，今夕是何年。
- **土家语 Ye拼音**：`ngaf havtair mefgarhaf cov, lartier qiev lunr?`
- **逐词**：ngaf（我）havtair（不知道）mefgarhaf（天上）cov（宫阙/屋），lartier（今晚）qiev（什么）lunr（年）
- **词典依据**：
  - 我 → `[ŋa³⁵]` (S词典183页, p0200，〈代〉我) → Ye: ngaf（ŋ→ng，35→f）
  - 不知道 → `[xa⁵³tʰai²¹]` (附录变调, p0569) → Ye: havtair（xa⁵³→hav，tʰai²¹→tair；又作 xa⁵³tʰai³⁵）
  - 天上 → `[mɤ³⁵ka²¹xa³⁵]` (S词典166页, p0183) → Ye: mefgarhaf（mɤ³⁵→mef，ka²¹→gar，xa³⁵→haf〔x→h，35→f〕；B词典 第1509条同形）
  - 宫阙 → `[ʦʰo⁵³]` 屋/房子 (S词典400页, p0417) → Ye: cov（宫阙无专词，以"天上的屋"近似，〔待核对〕）
  - 今晚 → `[la²¹tʰiɛ²¹]` (附录自由变调, p0568) → Ye: lartier（la²¹→lar，tʰiɛ²¹→tier）
  - 什么 → `[ʨʰiɛ⁵³]` (S词典354页, p0371 例句"ni³⁵ ʨʰiɛ⁵³ ni⁵⁵？你找什么？") → Ye: qiev
  - 年 → `[lũ²¹]` (S词典143页, p0160) → Ye: lunr（ũ→un，21→r）

#### **第3句**｜我欲乘风归去，又恐琼楼玉宇，高处不胜寒。
- **土家语 Ye拼音**：`ngaf xianv mefsuv mavjiv sunxkox, jiouf woxxox cov qiefxox, gaux gaux tax divxir wuxqix.`
- **逐词**：ngaf xianv（我想）mefsuv（风）mavjiv（骑/乘）sunxkox（归去），jiouf（又）woxxox cov（玉屋/琼楼玉宇）qiefxox（怕），gaux gaux（高高/高处）tax divxir（不能）wuxqix（冷）
- **词典依据**：
  - 想/欲 → `[ɕiã⁵³]` (S词典24页, p0041，②希望) → Ye: xianv
  - 风 → `[mɤ³⁵su⁵³]` (S词典170页, p0187) → Ye: mefsuv
  - 骑（乘之近似）→ `[ma⁵³ʨi⁵³]` (S词典147页, p0164，①骑，双腿跨坐) → Ye: mavjiv（"乘风"无专词，以"骑"代，〔待核对〕）
  - 归去/回去 → `[sũ⁵⁵kʰo⁵⁵]` (S词典266页, p0283「回，回来」) → Ye: sunxkox
  - 又 → `[jiou³⁵]` (见"有"词条例句"又买了几头牛"，p0044) → Ye: jiouf
  - 怕 → `[ʨʰiɛ³⁵xo⁵⁵]` (S词典355页, p0372，怕，害怕：zy²¹ mo²¹ ~. 老鼠怕猫) → Ye: qiefxox（原生词；另有 kɤ⁵³ 怕〔本字"惧"，汉语借词〕不取）
  - 玉 → `[wo⁵⁵xo⁵⁵]` (S词典418页, p0435，玉，玉石) → Ye: woxxox
  - 高 → `[kau⁵⁵]` (S词典314页, p0331) → Ye: gaux
  - 不 → `[tʰa⁵⁵]` (附录自由变调 p0568「tʰa⁵⁵ 不→tʰa⁵³」) → Ye: tax
  - 能 → `[ti⁵³ɕi²¹]` (附录变调 p0568「ti⁵³ɕi²¹ 能→ti⁵⁵ɕi²¹」) → Ye: divxir（t 不送气→d；53→v；ɕi²¹→xir）
  - 冷/寒 → `[wu³⁵ʨʰi⁵⁵]` (S词典425页, p0442) → Ye: wuxqix

#### **第4句**｜起舞弄清影，何似在人间。
- **土家语 Ye拼音**：`wuv qix lovrurlair gerciif, mefgarhaf qiev pier huanrjiarsiifsax.`
- **逐词**：wuv（舞）qix（清）lovrurlair（人影子/影）gerciif（玩），mefgarhaf（天上）qiev pier（何 像）huanrjiarsiifsax（凡间世上）
- **原意对应**：一转念头，想通了——天上仙境哪里比得上人间美好。
- **词典依据**：
  - 舞 → `[wu⁵³]` (S词典423页, p0440，舞) → Ye: wuv
  - 清 → `[ʨʰi⁵⁵]` (S词典357页, p0374，①澄澈) → Ye: qix
  - 人影子 → `[lo⁵³zu²¹lai²¹]` (S词典135页, p0152，人影子) → Ye: lovrurlair（"影"取此词族，〔待核对〕）
  - 玩 → `[kɤ²¹ʦʰɿ³⁵]` (S词典74页, p0091，玩) → Ye: gerciif
  - 像/相像 → `[pʰiɛ²¹]` (S词典227页, p0244，①像：ko³⁵ sɿ²¹ po²¹ ɕi²¹ kɤ⁵³ a²¹ niɛ⁵⁵ sɿ²¹ po²¹ ɕi²¹ ~. 她长得像她妈妈) → Ye: pier
  - 凡间世上 → `[xuã²¹ʨia²¹sɿ³⁵sa⁵⁵]` (S词典452页, p0469，凡间世上，世界上) → Ye: huanrjiarsiifsax（IPA x→Ye h 铁律；B词典第898条 huanf=总是 同声母印证）

#### **第5句**｜转朱阁，低绮户，照无眠。
- **土家语 Ye拼音**：`sursur mianxjiex cov sunx, nianfcuanx kuox dix sav, zauf taix nief.`
- **逐词**：sursur（月光）mianxjiex cov（红楼/朱阁）sunx（转），nianfcuanx kuox（窗里）dix sav（低低地洒），zauf（照）taix nief（没睡/无眠）
- **词典依据**：
  - 转 → `[sũ⁵⁵]` (S词典266页, p0283，①转，改变方向) → Ye: sunx
  - 红 → `[miã⁵⁵ʨiɛ⁵⁵]` (S词典156页, p0173，红) → Ye: mianxjiex（"朱阁"＝红楼，以"红＋屋"近似）
  - 低 → `[ti⁵⁵]` (附录借词调类 p0575「ti⁴⁴ 低→ti⁵⁵」，汉语借词) → Ye: dix
  - 洒 → `[sa⁵³]` (S词典239页, p0256，洒，使洒落) → Ye: sav（"低绮户"＝低低洒进绮户）
  - 亮窗/窗 → `[niã³⁵ʦʰuã⁵⁵]` (S词典176页, p0193，亮窗) → Ye: nianfcuanx（"绮户"＝雕花窗，以此近似，〔待核对〕）
  - 照 → `[ʦau³⁵]` (S词典367页, p0384，①照射) → Ye: zauf
  - 没有/没 → `[tʰai³⁵]` (见"有"词条：跟"tʰai³⁵ 没有"相对) → Ye: taix
  - 睡 → `[niɛ³⁵]` (S词典179页, p0196，①睡觉) → Ye: nief（"无眠"＝没睡）

#### **第6句**｜不应有恨，何事长向别时圆？
- **土家语 Ye拼音**：`tax cex xief livsiif, qiev sar hxer korloxlix.`
- **逐词**：tax cex（不该）xief（有）livsiif（恨），qiev sar（何事）hxer（长）korloxlix（圆）
- **词典依据**：
  - 该 → `[ʦʰɤ⁵⁵]` (S词典407页, p0424，助动词，该，理应如此) → Ye: cex
  - 恨 → `[li⁵³sɿ³⁵]` (S词典124页, p0141，恨，憎恨) → Ye: livsiif
  - 事 → `[sa²¹]` (S词典236页, p0253，③事) → Ye: sar（"何事"＝什么 事）
  - 长 → `[ɣɤ²¹]` (S词典416页, p0433，②远，空间或时间距离长) → Ye: hxer（B词典 第937条 hxer=长、远；comp.md 原方案 ɣ→hh 作 hher）
  - 圆 → `[kʰo²¹lo⁵⁵li⁵⁵]` (S词典89页, p0106，圆，圆圆) → Ye: korloxlix
  - "别时"（离别之时）无词典直证词条，此处省略，〔待核对〕

#### **第7句**｜人有悲欢离合，月有阴晴圆缺，此事古难全。
- **土家语 Ye拼音**：`lov xief ciif niev, sursur xief mefwufqix laurciirniex korloxlix xaxpargaf, gaivsar koxkiix korloxlix.`
- **逐词**：lov xief ciif niev（人 有 哭/悲 笑/欢），sursur xief mefwufqix laurciirniex korloxlix xaxpargaf（月 有 阴天 晴天 圆 缺），gaivsar koxkiix korloxlix（这事 难 圆/全）
- **词典依据**：
  - 人 → `[lo⁵³]` (S词典131页, p0148，人) → Ye: lov
  - 哭（悲之近似）→ `[ʦʰɿ³⁵]` (S词典374页, p0391，哭) → Ye: ciif（注意送气 ʦʰ→c）
  - 笑（欢之近似）→ `[niɛ⁵³]` (S词典179页, p0196，笑) → Ye: niev（"悲欢"以"哭/笑"近似；"离合"无直证，省略，〔待核对〕）
  - 阴天 → `[mɤ³⁵wu³⁵ʨʰi⁵⁵]` (S词典169页, p0186，阴天) → Ye: mefwufqix
  - 晴天 → `[lau²¹ʦʰɿ²¹niɛ⁵⁵]` (S词典112页, p0129，天晴天，晴天) → Ye: laurciirniex
  - 缺 → `[xa⁵⁵pʰa²¹ka³⁵]` (S词典433页, p0450，缺，缺缺，表状态) → Ye: xaxpargaf
  - 这事 → `[kai³⁵ sa²¹]` (见"该"词条例句"kai³⁵ sa²¹ li²¹ 这事该说") → Ye: gaivsar
  - 难 → `[kʰo⁵⁵kɨ⁵⁵]` (S词典88页, p0105，①难，不容易) → Ye: koxkiix（ɨ 按 comp.md 归 ɿ→ii）
  - "古"（自古）无直证；"全"（两全）以"圆"korloxlix 代，〔待核对〕

#### **第8句**｜但愿人长久，千里共婵娟。
- **土家语 Ye拼音**：`ngaf xianv lov hxer, qianx liv sursur tunr bav.`
- **逐词**：ngaf xianv（我只愿/但愿）lov hxer（人 长久），qianx liv（千 里）sursur tunr bav（月 同 看）
- **词典依据**：
  - 千 → `[ʨʰiã⁵⁵]` (S词典351页, p0368，千) → Ye: qianx（ʨʰ→q，iã→ian，55→x）
  - 里 → `[li⁵³]` (S词典123页, p0140，〈量〉里，市制长度单位) → Ye: liv
  - 同/共 → `[tʰũ²¹]` (S词典323页, p0340，同，相同) → Ye: tunr
  - 看 → `[pa⁵³]` (附录韵母例词 p0564「a | pa⁵³ | 看」) → Ye: bav（p 不送气→b，53→v）
  - 婵娟＝明月 → sursur
