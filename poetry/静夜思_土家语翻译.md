## 第二层：解析（详解）

### 第1句｜床前明月光

- **Ye拼音**：`niɛ³⁵ jiɛ⁵⁵pai⁵⁵ sursur kaxkax`
- **逐词**：niɛ³⁵（床）jiɛ⁵⁵pai⁵⁵（边上）sursur（月亮/月光）kaxkax（亮亮的）
- **直译**：床 边上 月光 亮亮的
- **与原诗差异**：「明月光」简化为 sursur kaxkax（月光 亮亮的），字数对齐5字
- **词典依据**：
  - 床 → [niɛ³⁵]（正文180页，通过 niɛ³⁵ʦʰo⁵⁵ 表达；B词典 nief 一致）
  - 前 → **jiɛ⁵⁵pai⁵⁵**（边上/边缘，正文46页/page_0063，词典例句「niɛ³⁵ʦo⁵⁵ jiɛ⁵⁵pai⁵⁵ 床边上」完美对应；⚠️ 三源校对发现原 ne²¹ 无词典支撑，已替换）
  - 月光 → su²¹su²¹（正文262页，三源完全一致：S词典 su²¹su²¹ / B词典 sursur / T词典 su²¹su²¹）
  - 亮亮 → kaxkax（⚠️ 三源校对：B词典 kax=花费时间（非"亮"义）；S词典无 kaxkax=亮 独立词条。此处为创造性用法，标注）

### 第2句｜疑是地上霜

- **Ye拼音**：`pier sɿ²¹tʰiɛ²¹ ka²¹ pu⁵⁵li⁵⁵`
- **逐词**：pier（像/似乎是）sɿ²¹tʰiɛ²¹（地）ka²¹（上）pu⁵⁵li⁵⁵（霜）
- **直译**：像 地 上 霜
- **与原诗差异**：「疑是」简化为 pier（像），SOV 语序：地 上 霜 = 宾语在前
- **词典依据**：
  - 像 → [pʰiɛ²¹]（正文244页）→ Ye: pier（⚠️ B词典中pier=分开，非"像"；S词典确认pʰiɛ²¹=像，以S词典为准）
  - 地/田 → [sɿ²¹tʰiɛ²¹]（正文269页，S词典释为"田"，泛指土地）
  - 上 → [ka²¹]（正文70页，方位词）
  - 霜 → [pu⁵⁵li⁵⁵]（正文207页）

### 第3句｜举头望明月

- **Ye拼音**：`kʰo⁵⁵pa⁵⁵ ti⁵⁵ti⁵⁵ sursur bav`
- **逐词**：kʰo⁵⁵pa⁵⁵（头）ti⁵⁵ti⁵⁵（抬/举）sursur（月亮）bav（看/望）
- **直译**：头 抬 月亮 看
- **结构**：动词 ti⁵⁵ti⁵⁵（抬）为辅助动作，bav（看）为主要动词收尾；宾语 sursur 在主要动词前（SOV ✓）
- **词典依据**：
  - 头 → [kʰo⁵⁵pa⁵⁵]（正文101页）
  - 抬/举 → [ti⁵⁵ti⁵⁵]（正文285页，同"举"）
  - 看/望 → [pa⁵³]（正文189页）
  - 月亮 → su²¹su²¹（正文262页）

### 第4句｜低头思故乡

- **Ye拼音**：`kʰo⁵⁵pa⁵⁵ kʰu³⁵kʰu⁵⁵ wo³⁵tʰu⁵⁵ tiɛ³⁵`
- **逐词**：kʰo⁵⁵pa⁵⁵（头）kʰu³⁵kʰu⁵⁵（勾/低）wo³⁵tʰu⁵⁵（家里/家乡）tiɛ³⁵（想/思念）
- **直译**：头 勾 家里 想
- **结构**：动词 kʰu³⁵kʰu⁵⁵（勾/低）为辅助动作，tiɛ³⁵（想）为主要动词收尾；宾语 wo³⁵tʰu⁵⁵ 在主要动词前（SOV ✓）
- **借词替换**：「思」用 tiɛ³⁵（想/思念，正文292页原生词），不用 ɕiã⁵³（借词想）
- **「故乡」处理**：无直接对应词，用 wo³⁵tʰu⁵⁵（里/家里，引申为"家乡"）
- **词典依据**：
  - 勾/低 → [kʰu³⁵kʰu⁵⁵]（正文94页，头向下垂）
  - 想/思念 → [tiɛ³⁵]（正文292页，义项②想念：在外面待久了，我很想我的父母亲）
  - 家/家乡 → wo³⁵tʰu⁵⁵（里/里面，引申为"家乡"）
