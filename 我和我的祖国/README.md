# 《我和我的祖国》土家语译本研究 · 归档

本目录收录《我和我的祖国》土家语译本的**四版核心稿**（不含音视频），按版本分文件归档，用于词源对照、分歧标注与后续研究。

## 版本谱系

| 版本 | 译者 / 署名 | 形态 | 时间 | 词源路线 |
|---|---|---|---|---|
| 搜狐版 | 彭军 译 | 早期公开文本，16 行（前两段） | 2019-05-07 | 民歌 / 山歌口传 |
| 龙山版 | 彭军 原译 + 田禹顺 改 | 完整版（三段） | 2019-10-02 | 民歌 / 山歌口传 |
| 来凤版 | 储永明 译音 | 手稿片段 + 视频字幕 | 2019-09 | 方言教学 / 教师口传 |
| 巴兜版 | 巴兜 | 自学译稿，逐词对照 | 2026 | 2021 商务本 |

> 搜狐版与龙山版为**同一份底稿的两个时点**（5 月彭军原译首发 → 10 月田禹顺修改后完整版），非两个独立译本。
