# 《我的祖国》土家语歌词翻译

> 译制说明：本译稿为歌词意译，遵循土家语 SOV 语序，按《土家语翻译技能》检查清单逐项核对。歌词大量修辞（波浪宽、明媚、英雄、猎枪、和平、阳光）在土家语中无对应专词，采用「近似义最贴合」策略并标注近似替代。
>
> **语气词处理（本版本策略：逐词保留）**：汉语「就/那/呀/了」等语气副词、指示代词、完成体标记、感叹语气按用户要求**逐词译出**，不省略：
>
> - 「就」（正是/立即/强调）→ `boxgaf`（T词典：`po⁵⁵ka³⁵`「就是/正是」；副词义）
> - 「那」（远指）→ `aixnaux`（T词典：`ai⁵⁵nau⁵⁵`「那个」）／`aix`（T词典：`ai⁵⁵` 指示代词）
> - 「了」（完成体助词）→ `liaux`（T词典 附录·贰·五：完成体 `liau⁵⁵`）
> - 「呀」（句末感叹语气）→ `o`（S词典语用规则：动词/句子自带感叹意味时可不另加；副歌句末加 `o` 承载抒情性）
>
> 拼音采用 1984 叶德书-彭秀模土家语拼音方案：**全小写、无送气上标（´）**；声调尾字母严格对应 **55→x、53→v、35→f、21→r**（T词典 IPA 为唯一声调基准，comp.md 规则）；声母清不送气 `p/t/k/ʦ/ʨ→b/d/g/z/j`、送气 `pʰ/tʰ/kʰ→p/t/k`、`x→h`；韵母 `ɤ→e、ɿ→ii、ã→an、ũ→un`。语法标记 `po²¹`（着/的）`la⁵⁵`（着）等按技能规则保留原状不转调尾，写作 `po lax`。
>
> 主要依据：S词典、T词典、B词典 映射表。

### 附：副歌抒情尾声（「呀」气）

副歌三遍在结尾可各加语气 `o` 以承载汉语副歌句末感叹「呀」的抒情气：

```
enx [X] niex kuairjiax six o       （这……的祖国 o）
enx ngaf hxunf niex lanr six o
enx tier [X] niex ligax gar wunr o
mefpixmefzav [X] niex xief o
```

> `o` 为土家语句末感叹语气词（S词典语用规则），副歌抒情句加用；主歌叙述句不加。

## 三、逐段详解（IPA + 逐词直译 + 依据）

> Ye 拼音按《土家语翻译技能》转写规则生成：全部小写，无送气上标（´）；清不送气 `p/t/k/ʦ/ʨ→b/d/g/z/j`、送气 `pʰ/tʰ/kʰ→p/t/k`、`x→h`；韵母 `ɤ→e、ɿ→ii、ã→an、ũ→un`；调尾 `55→x/53→v/35→f/21→r`。

### 主歌一（大河·两岸）

**1. 一条大河波浪宽**
`lar dor tiefbax hurpar, boxlanx kuax`
- `lar` [la²¹] 一（数量词）
- `dor` [to²¹] 条（量词，IPA t→d）
- `tiefbax` [tʰiɛ³⁵pa⁵⁵] 大（T词典：p0333；tʰ→t / p→b）
- `hurpar` [xu²¹pʰa²¹] 河（T词典：p0464；x→h / pʰ→p）
- `boxlanx` [po⁵⁵lã⁵⁵] 波浪（T词典：p0222；p→b / ã→an）
- `kuax` [kʰua⁵⁵] 宽（T词典：p0113；kʰ→k）
- 直译：一条 大 河，波浪 宽
- 结构：名词短语 + 形容词谓语（SOV，形容词作谓语）

**2. 风吹稻花香两岸**
`mef sux, lifbuf kaxpeix xianx hurpar hof nganfsanx`
- `mef` [mɤ³⁵] 风（T词典：`mɤ³⁵su⁵³` p0187 词根；ɤ→e）
- `sux` [su⁵⁵] 吹
- `lifbuf` [li³⁵pu⁵⁵] 稻谷/谷子（T词典：p0142〈名〉谷子→稻子/稻谷；IPA p→b）
- `kaxpeix` [kʰa⁵⁵pʰei⁵⁵] 花（T词典：p0039 香例句 / p0089 桂花词条；kʰ→k / pʰ→p）
- `xianx` [ɕiã⁵⁵] 香（T词典：p0039；ɕ→x / iã→ian）
- `hurpar` [xu²¹pʰa²¹] 河（T词典：p0464）
- `hof` [xo³⁵] 两（x→h / 35→f）
- `nganfsanx` [ŋã³⁵sã⁵⁵] 岸上（T词典：p0202；ŋ→ng / ã→an）
- 直译：风 吹，稻谷 花 香，河 两 岸上（「两岸」＝河两边，非河对岸）

**3. 我家就在岸上住**
`ngaf cuv boxgaf nganfsanx wunr`
- `ngaf` [ŋa³⁵] 我（ŋ→ng）
- `cuv` [ʦʰu⁵³] 家/屋（T词典：p0420；ʦʰ→c / 53→v）
- `boxgaf` [po⁵⁵ka³⁵] 就/正是（T词典 p95：「就是」；p→b / k→g）
- `nganfsanx` [ŋã³⁵sã⁵⁵] 岸上（T词典：p0202；ŋ→ng / ã→an）
- `wunr` [wũ²¹] 住（T词典：p0448：`wũ²¹` ③住，居住；ũ→un / 21→r）
- 直译：我 家 就 岸上 住
- 结构：副词 `boxgaf` 表「正是」，`wunr` 收尾

**4. 听惯了艄公的号子**
`boxzov jefmif xiv po lax liaux`
- `boxzov` [pu⁵⁵tso⁵⁵] 船夫（T词典：`buvzov`；p→b / ts→z）
- `jefmif` [tɕe³⁵mi³⁵] 号子（T词典：`jefmif`；tɕ→j）
- `xiv` [ɕi⁵³] 听（T词典：p0036；ɕ→x / 53→v）
- `po lax` [po²¹la⁵⁵] 惯（经验体，T词典 附录·贰·五）
- `liaux` [liau⁵⁵] 了（完成体，T词典 附录·贰·五）
- 直译：船夫 号子 听 惯 了
- 结构：SOV + 经验体 + 完成体

**5. 看惯了船上的白帆**
`buv gar asii jirlar po lax liaux`
- `buv` [pu⁵³] 船（T词典：p0226；p→b / 53→v）
- `gar` [ka²¹] 上（T词典：p0070：`ka²¹` 方位词；k→g / 21→r）
- `asii` [a⁵⁵si⁵⁵] 白帆（近似：白 + 帆意象，土家语无「帆」专词）
- `jirlar` [ji²¹la²¹] 看见（T词典：`jirlar`）
- `po lax` 惯（经验体）
- `liaux` 了（完成体）
- 直译：船 上 白帆 看 惯 了

### 副歌·第一遍（美丽·辽阔·明媚）

**6. 这是美丽的祖国**
`enx zex niex kuairjiax six`
- `enx` [ẽ⁵⁵] 这（T词典：p0050：`ẽ⁵⁵` 指示代词，近指；ẽ→en）
- `zex` [ze⁵⁵] 美丽（T词典：`rev` 汉借）
- `niex` [niɛ⁵⁵] 的（T词典：p0194：`niɛ⁵⁵` 助词，用在定语后）
- `kuairjiax` [kuai²¹ʨia⁵⁵] 祖国（T词典：p0086；ʨ→j）
- `six` [si⁵⁵] 是（判断句保留系词）
- 直译：这 美丽 的 祖国 是
- 结构：判断句 SOV，指示词 `enx` 前置，`niex` 连接定语与中心语

**7. 是我生长的地方**
`enx ngaf hxunf niex lanr six`
- `enx` 这（承接上句主语）
- `ngaf` 我；`hxunf` 生长
- `niex` 的（T词典：p0194）
- `lanr` 地方；`six` 是
- 直译：这 我 生长 的 地方 是
- 结构：`enx` 作主语（上句「这」的延续），`six` 收尾

**8. 在这片辽阔的土地上**
`enx tier cixlercix niex ligax gar wunr`
- `enx` 这；`tier` 片
- `cixlercix` [tsʰi⁵⁵le²¹tsʰi⁵⁵] 辽阔（tsʰ→c）
- `niex` 的（T词典：p0194）
- `ligax` 土地
- `gar` [ka²¹] 上（T词典：p0070；k→g / 21→r）
- `wunr` [wũ²¹] 在（T词典：p0448：③住，居住；ũ→un / 21→r）
- 直译：这 片 辽阔 的 土地 上 在
- 结构：`wunr` 收尾，表「在」义

**9. 到处都有明媚的风光**
`mefpixmefzav lianfxuaxxuax niex xief`
- `mefpixmefzav` [mɤ³⁵pʰi⁵⁵mɤ³⁵za⁵³] 到处（T词典：p0187；pʰ→p / 53→v）
- `lianfxuaxxuax` [liã³⁵xua⁵⁵xua⁵⁵] 明媚（近似：明亮）
- `niex` 的（T词典：p0194）
- `xief` [ɕiɛ³⁵] 有（存在句）
- 直译：到处 明媚 的 有
- 注：「风光」在土家语中无对应专词，以「明媚」承载；`niex` 连接定语「明媚」与隐含中心语

**10. 姑娘好像花儿一样**
`kifziif kaxpeix davzer`
- `kifziif` [kʰi³⁵tsɿ³⁵] 姑娘（近似：小姐 + 姑；kʰ→k / ts→z / ɿ→ii）
- `kaxpeix` [kʰa⁵⁵pʰei⁵⁵] 花（T词典：p0095；kʰ→k / pʰ→p）
- `davzer` [ta⁵³ʦɤ²¹] 像……一样（T词典：p0294；t→d / ʦ→z / ɤ→e）
- 直译：姑娘 花 像……一样（喻词居后）

**11. 小伙儿心胸多宽广**
`kufkor xianfkuf kuax`
- `kufkor` [kʰu³⁵kʰo²¹] 小伙（近似：男孩 + 伙；kʰ→k）
- `xianfkuf` [ɕiã³⁵kʰu³⁵] 心胸（近似：心 + 胸/量；ɕ→x / kʰ→k）
- `kuax` [kʰua⁵⁵] 宽
- 直译：小伙，心胸 宽

**12. 为了开辟新天地**
`lar nixxuanfgax ni ni`
- `lar` 新（近似）
- `nixxuanfgax` [ni⁵⁵xuan³⁵ka⁵⁵] 天地（k→g）
- `ni` 开；`ni` 目的/为
- 直译：新 天地 开辟

**13. 唤醒了沉睡的高山**
`kuxcax chiaf lianr liaux`
- `kuxcax` [kʰu⁵⁵ʦʰa⁵⁵] 山/高山（kʰ→k / ʦʰ→c）
- `chiaf` [ɕia³⁵] 沉睡（近似；ɕ→x）
- `lianr` [liã²¹] 醒/唤醒（T词典：`liã²¹`）
- **`liaux` [liau⁵⁵] 了**（T词典 附录：完成体 `liau⁵⁵`；55→x）
- 直译：高山 沉睡 醒 **了**

**14. 让那河流改变了模样**
`aixnaux sufliv czifcof liaux`
- **`aixnaux` [ai⁵⁵nau⁵⁵] 那**（T词典：「那个」p121）
- `sufliv` [su³⁵li⁵³] 河流
- `czifcof` [tzʰi³⁵kʰo³⁵] 改变（动词链，近似）
- `liaux` 了（完成体）
- 直译：**那** 河流 改 变 **了**

### 副歌·第二遍（英雄·古老·青春）

**15. 这是英雄的祖国**
`enx herof niex kuairjiax six`
- `enx` 这（T词典：p0050）；`herof` 英雄（汉借，近似）
- `niex` 的（T词典：p0194）；`kuairjiax` 祖国；`six` 是
- 直译：这 英雄 的 祖国 是

**16. 是我生长的地方**
`enx ngaf hxunf niex lanr six`（同 7）

**17. 在这片古老的土地上**
`enx tier lavgu niex ligax gar wunr`
- `enx` 这；`tier` 片；`lavgu` 古老（近似）
- `niex` 的；`ligax` 土地；`gar` 上；`wunr` 在
- 直译：这 片 古老 的 土地 上 在

**18. 到处都有青春的力量**
`mefpixmefzav cifxuaf niex lilaf xief`
- `cifxuaf` 青春（汉借）；`niex` 的；`lilaf` 力量（汉借）；`xief` 有
- 直译：到处 青春 的 力量 有

### 主歌三（山好·路好·酒·猎枪）

**19. 好山好水好地方**
`caf kuxcax, caf sux, caf lancan`
- `caf` [tsʰa³⁵] 好（tsʰ→c / 35→f）；`kuxcax` 山；三段排比

**20. 条条大路都宽畅**
`lula lutar toif kuax`
- `lula lutar` 条条大路；`toif` [tʰo³⁵] 宽大（tʰ→t）；`kuax` 宽

**21. 朋友来了有好酒**
`buxliv zufziif liaux, xuafziif xief`
- `buxliv` [pu⁵⁵li⁵³] 朋友（p→b）
- `zufziif` [zu³⁵ɿ³⁵] 来（ɿ→ii）
- **`liaux` 了**（完成体）
- `xuafziif` 好酒（近似：xuaf 好 + ziif 酒）
- `xief` 有
- 直译：朋友 来 **了**，好 酒 有

**22. 若是那豺狼来了**
`aixnaux lav zufziif liaux`
- **`aixnaux` 那**（T词典 p121：「那个」`ai⁵⁵nau⁵⁵`）
- `lav` [lɑ⁵³] 狼（T词典：`lav`；豺狼以「狼」承载，T词典）
- `zufziif` [zu³⁵ɿ³⁵] 来（ɿ→ii）
- **`liaux` 了**（完成体）
- 直译：那 **狼** 来 **了**
- 结构：**「若是」无对应条件连词**，省略；以完成体 `liaux`＋语境承接连贯（勿用 `taif`＝`tʰai³⁵`，B词典第 2223 条该词为「没/没有」，词义冲突）

**23. 迎接它的有猎枪**
`liafgif ief lav`
- `liafgif` [lia³⁵ki³⁵] 猎枪（近似：猎 + 枪；k→g）
- `ief` [ie³⁵] 迎
- `lav` 它/狼（承接上句宾语）
- 直译：猎枪 迎 狼

## 八、说明与遗留

- **「这」指示代词**：S词典 p0050 收 `ẽ⁵⁵`（指示代词，近指），Ye 转写 `enx`。副歌判断句「这是……的祖国」统一用 `enx`，非 `aix`（`ai⁵⁵`）或 `lar`（`la²¹`）。
- **「的」结构助词**：S词典 p0194 收 `niɛ⁵⁵`（助词，用在定语后），Ye 转写 `niex`。用于「美丽的祖国」「辽阔的土地」等修饰结构，替代前版 `po lax`。
- **「在」动词**：S词典 p0448 收 `wũ²¹`（动词，③住，居住），Ye 转写 `wunr`。用于「在这片……土地上」，收尾表「在」义。
- **「上」方位词**：S词典 p0070 收 `ka²¹`（方位词，上），Ye 转写 `gar`。用于「土地上」「船上」。
- **「大」形容词**：S词典 p0333 收 `tʰiɛ³⁵pa⁵⁵`（形容词，大），Ye 转写 `tiefbax`。用于「大河」。
- **「两岸」**：S词典 p0202 收 `ŋã³⁵sã⁵⁵`（岸上），Ye 转写 `nganfsanx`。「两岸」译为 `hof nganfsanx`（两 岸上），非 `cerjiexbix`（河对岸 `ʦʰɤ²¹ʨiɛ⁵⁵pi⁵⁵`，p0427）。
- **「一样」**：S词典 p0294 收 `ta⁵³ʦɤ²¹`（像……一样），Ye 转写 `davzer`。用于「花儿一样」。
- **「就」副词义**：T词典词典「就是 `po⁵⁵ka³⁵`」是副词，本译取此义作「正是/立即」，Ye 转写 `boxgaf`。
- **「那」指示代词**：T词典「那个 `ai⁵⁵nau⁵⁵`」较完整（Ye `aixnaux`），用作「那河流」「那豺狼」的「那」。
- **「了」完成体**：土家语完成体标记 `liau⁵⁵`（Ye `liaux`）与汉语「了」高度对应，用于「听惯了/看惯了/唤醒了/改变了/来了」等句末。
- **「呀」感叹语气**：原歌词文本无「呀」汉字，故无对应词位；副歌抒情句按土家语语用规则可加句末 `o`（感叹词），已在附例中给出，实际演唱时可选择不加。
- **「若」条件连词**：土家语无对应条件连词。「若是那豺狼来了」省略「若」，以完成体 `liaux`＋语境承接连贯。**注意勿用 `taif`**——B词典 词表第 2223 条 `tʰai³⁵`（`taif`）实为「没/没有」，作「若」属词义误配，已修正。
- **「风光」名词**：土家语无「风光」专词，并入「明媚」承载；以 `niex` 连接定语「明媚」与隐含中心语。
- **未查证项**：英雄（`herof`）、强大（`tif`）、和平（`xua`）、沉睡（`chiaf`）等为无直接词典证据的汉借/近似承载，已在近似替代表中标注，建议传承人复核。
