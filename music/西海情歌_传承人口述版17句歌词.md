# 《西海情歌》传承人口述版 17 句歌词

> 说明：本稿以传承人 **田剑英** 的演唱（用户西南官话汉字记音）为据，把口述解码回土家语，并拼合成「西海情歌」歌词实际的 **17 句**。汉字记音是「近似音」，丢失声调，故本文按S词典S词典 词条补注调值；Ye 拼音声调尾字母严格 55→x / 53→v / 35→f / 21→r。
>
> 拼合说明（由解码 20 行合并为 17 句）：候鸟句（11+12）、温暖春天句（15+16）、归来的孤雁句（17+18），断开的三行已拼回完整句。
>
> 拼音采用 1984 叶德书-彭秀模土家语拼音方案，声调以 S词典 IPA 为唯一基准。
>
> **对音说明（重要）**：按传承人记音逐音节核验，L1–L6、L13、L17 的核心实词可与记音一一对上；而 L8/L9/L11/L14/L15/L16 中的「高原、苍茫、孤雁、一直、春天、续情缘」等**抽象意象在土家语中无对应专词**，译文仅为"近义词意译"，汉字记音只能承载前几个核心词（等待/雪/山/回/爱等），**无法逐字对应**。此类行标 `[意译·待复核]`，须由传承人最终定稿。
>
> **词形基准（方法B 定标）**：整套歌词**以S词典S词典 为主**——凡 S词典 已收的词一律用其词形/IPA/页码；S词典 未收者用T词典T词典补表；B词典 音形表**仅作跨典音形线索与命名基准**，不作成稿词形来源。此基准下，三大跨典冲突词锁定如下：「话」＝S词典 `xaf`[sa²¹]（不用 B词典 `sar`）、「不/无」＝S词典 `taf`[ta³⁵]（不用 B词典 `tav/taif`）、「回」＝S词典 `sunxkox`[sũ⁵⁵kʰo⁵⁵]（B词典 同形佐证）。汉字记音与 Ye 拼音转写规则见文末。

## 二、逐句详解（按记音对音）

**1. 自你离开以后** `Nif afqef liex, aixtairlex`
- `Nif` [ni³⁵] 你；`afqef` [a³⁵tɕʰe³⁵] 离开（T词典；S词典 索引 415 正向词为 `ɣɨ³⁵` 走）；`liex` [liɛ⁵⁵] 完成助词"了"（S词典 p144，用在动词后表随动作离开）；`aixtairlex` [ai⁵⁵ tʰai²¹ le⁵⁵] 从此/此后（T词典「从此 aivtailev」，Ye 按 55→x/21→r 转写；歌唱中首音节「哎 ai⁵⁵」弱化，记音作「塔列」）
- 记音对音：你(你) / 阿且(离开) / 列(了) / 塔列(此后)——逐一对应。

**2. 从此就丢了温柔** `Aixliex jiux lovhueif naflex`
- `Aixliex` [ai⁵⁵liɛ⁵⁵] 从此（p12，〈副〉①从此 ②〈连〉然后）；`jiux` [ʨiou³⁵] 就（S词典 借音／B词典 承接连词）；`lovhueif` [lo⁵³xuei³⁵] 温柔/暖和（p152 〈形〉①暖和 ②温不冷不热）；`naflex` [na³⁵ le⁵⁵] 丢掉了（T词典「丢掉 naflev」）
- 记音对音：嗡聊(从此) / 救(就) / 罗锡(温柔) / 纳聊(丢掉)——逐一对应。

**3. 等待在这雪山路漫长** `Tivbo sufsux kux, lav hxerbar`
- `tivbo` [tʰi⁵⁵po²¹] 等待（T词典「等待 tivbo」，S词典 等＝tʰi⁵⁵ p327，-po²¹=持续"着"）；`sufsux` [su³⁵su⁵⁵] 雪（p279）；`kux` [kʰu⁵⁵] 山（词根，合"雪山"）；`lav` [la⁵³] 路（p121）；`hxerbar` [ɣɤ²¹pa²¹] 长/漫长（书页416＝文件0433 〈形〉表状态，例句「kai³⁵ la⁵³ la³⁵ ʦɿ⁵⁵ ɣɤ²¹pa²¹ 这一条路长」直证，即「拉尔吧＝路漫长」整词 `lav hxerbar`）；「恩」＝衬音（无主语「我」，不译 `ngaf`）
- 记音对音：体博(等待) / 恩(衬) / 俗俗(雪) / 苦(山) / 拉尔吧(路·漫长)——逐一对应。
- 语序完全照演唱记音，不做 SOV 重排。

**4. 听寒风呼啸依旧** `Zefsuv sax sux, xila`
- `zefsuv` [zɤ³⁵su⁵³] 风（p187，又说 `mɤ³⁵su⁵³`）；`sax` [sa⁵⁵] 冷（T词典「寒冷 sav」，对记音「嗨」，s/h 记音近似）；`sux` [su⁵⁵] 吹，刮（风）（p278）；`xila` [ɕi²¹la²¹] 听（T词典「听见」，」「嗡」衬音、「啦」）
- 记音对音：入(衬) / 热索(风) / 嗨亚(冷·吹) / 嗡啦(听)——「依旧」无记音依据，不译。

**5. 一眼望不到边** `Lovpux puv jiex taf borlor`
- `lovpux` [lo³⁵pu⁵⁵] 眼（例 p42/p46）；`puv` [pu³⁵] 看/望（p227）；`jiex` [jiɛ⁵⁵] 到（p62）；`borlor` [po⁵⁵lo²¹] 边（p222）；`taf` [ta³⁵] 不
- 记音对音：裸不(眼) / 拔(望) / 几黑(不到) / 侧(边)——逐一对应。

**6. 风似刀割我的脸** `Zefsuv tortor, ngaf kuf ngax`
- `zefsuv` 风；`tortor` [tʰo²¹tʰo²¹] 刀（例 p42/p50）；`ngaf` [ŋa³⁵] 我（p200）；`kuf` [ku³⁵] 脸（p84）；`ngax` [ŋa⁵⁵] 割（p199，〈动〉割，用刀截断植物茎叶）
- 记音对音：热苏(风) / 脱脱(刀) / 伢(我) / 顾(脸) / 哈(割)——逐一对应。「似」无记音依据，比喻义由结构承载。

**7. 等不到西海天际蔚蓝** `Tix taf to, hur mef langavci`
- `tix` [tʰi⁵⁵] 等（p327）；`taf` [ta³⁵] 不；`to` [to²¹] 到（对记音「侧」）；`hur` [xu²¹] 湖/海（T词典「湖 hu」，对记音「西海」，取义"海"）；`mef` [mɤ³⁵] 天（p183）；`langavci` [lã²¹ ka⁵⁵ tsʰi²¹] 蓝/蔚蓝（T词典「蓝色」，对记音「汉嘎嘎」，l/h 记音近似）
- 记音对音：体黑侧(等不到) / 西海(海) / 篾(天) / 汉嘎嘎(蔚蓝)——「西」衬音。

**8. 无言这苍茫的高原** `Xaf taf, hauhau kuxgar` `[意译·待复核]`
- `xaf` [sa²¹] 话/言（p253）；`taf` [ta³⁵] 无；`hauhau` [xau²¹xau²¹] 茫茫/苍茫（T词典「茫茫 hauhau」）；`kuxgar` [kʰu⁵⁵ka²¹] 山+上=高原/高地（义译构拟）
- **对音提示**：土家语无"焦虑/若有所思的沉默了"等抽象名词专词，「无言」「苍茫」「高原」均为近义意译；记音「你兹太捏」与 `xaf taf` 仅部分对应，需传承人复核演唱切分。

**9. 还记得你答应过我** `Defbox, nif ngaf tif tor` `[意译·待复核]`
- `defbox` [te³⁵po⁵⁵] 记得（义译，对记音「爹波」）；`nif` 你；`ngaf` 我；`tif` [tʰi³⁵] 答应（S词典 p330 〈动〉①答应，应声回答；T词典「答应 tif」）；`tor` [to²¹] 了/过
- **对音提示**：「爹波」近"记得、" 体的对音成立，但「洒体波西伢」完整切分需传承人复核。

**10. 不会让我把你找不见** `Dox lier ngaf, nif nix jirtauv taf`
- `dox` [to⁵⁵] 会（p310）；`lier` [liɛ²¹] 让（p145）；`ngaf` 我；`nif` 你；`nix` [ni⁵⁵] 找（p188）；`jirtauv` [ji²¹tau³⁵] 不见/丢了（p54）；`taf` 不
- 记音对音：你呢(你) / 作太(会让?) / 捏汗(找不见) / 他日(不)——部分对应，其余为语序补足。

**11. 可你跟随那南归的候鸟飞得那么远** `Nif nafgof, miefcax sunxkox; zax hafnav hxer` `[意译·待复核]`
- `nafgof` [na³⁵ko³⁵] 跟随（T词典「跟随 nafgof」，对记音「果老」）；`miefcax` [miɛ²¹ʦʰa⁵⁵] + `sunxkox` 南归候鸟（义译，土家语无"候鸟"专词）；`zax` [za⁵⁵] 飞（T词典〈动〉飞，对记音「列比ra」尾）；`hafnav` [xa³⁵na⁵⁵] 那么（T词典）；`hxer` [ɣɤ²¹] 远（长义引申）
- **对音提示**：「果老」＝跟随、尾「那尔」≈那么·远 成立；「南归候鸟」为义译构拟，需传承人确认。

**12. 爱像风筝断了线** `Afciix huxzef, tuvmur lavlur`
- `afciix` [a³⁵ʦʰɿ⁵⁵] 爱（p28）；`huxzef` [xu⁵⁵ʦɛ⁵⁵] 风筝（S词典 p47 天空? 实际，书页），对记音「洪整」；`tuvmur` [tʰu⁵⁵mu²¹] 线（T词典「棉线 tuvmu」，对记音「铜蒙」）；`lavlur` [la⁵⁵lu²¹] 断/断绝（T词典「断绝 lavlu」，对记音「爹」）
- 记音对音：阿此(爱) / 洪整(风筝) / 铜蒙(线) / 爹(断)——逐一对应。

**13. 也拉不住你许下的诺言** `Bef ciivciir taf to nif, her box xix xaf`
- `bef` [pɤ⁵⁵] 也（p229）；`ciivciir` [ʦʰɿ⁵³ʦʰɿ²¹] 拉（p416 ①拉 ②扯 ③提拔）；`taf` [ta³⁵] 不；`to` 住；`nif` 你；`her` [xɤ²¹] 许/答应（书页456＝文件0473）；`box xix` po⁵⁵ɕi⁵⁵ ……的（定语助词）；`xaf` [sa²¹] 话/诺言（p253）
- 记音对音：也(也) / 黑测(拉) / 你(你) / 黑(许) / 波西(的) / 捏撒(话)——逐一对应。

**14. 我在苦苦等待雪山之巅温暖的春天** `Ngaf cucu tixbor, sufsux kux liauxkuxlix lovhoxueix mef` `[意译·待复核]`
- `cucu` [ʦʰu²¹ʦʰu²¹] 一直（T词典「一直 cucu」，S词典 未收故用T词典；B词典 `curcur`〔直〕作旁证；对记音「尼」）；`tixbor` 等待；`sufsux kux` 雪山；`liauxkuxlix` 山巅（p「山顶 liau⁵⁵kʰu⁵⁵li⁵⁵」，对记音「扎卡涛」）；`lovhoxueix` [lo⁵³xo²¹xuei⁵⁵] 温暖（p152）；`mef` [mɤ³⁵] 天/春
- **对音提示**：「俗俗苦」雪山、「裸活辉」温暖可对上；「春天」土家语无专词，以 `mef`(天) 近似；"苦苦"、「之巅」为意译，需传承人确认。

**15. 等待高原冰雪融化之后，归来的孤雁** `Tixbor, kuxgar sufsux lianr tor avlev, sunxkox nefbif` `[意译·待复核]`
- `tixbor` 等待；`kuxgar` 高原（义译构拟）；`sufsux` 雪；`lianr` [liã²¹] 化/融化（义译，对记音「融几」）；`tor` 了；`avlev` [a⁵⁵le⁵⁵] 之后（T词典，对记音「他捏」）；`sunxkox` 回；`nefbif` [ne³⁵pi³⁵] 鸟/雁（T词典「鸟 nefbif」，对记音「捏捏比」）
- **对音提示**：等待/雪/之后/回/鸟 可对应；「高原」「冰雪融化」「孤雁」为义译，需传承人确认。

**16. 爱再难以续情缘** `Afciix aixlex jefbox taf` `[意译·待复核]`
- `afciix` 爱；`aixlex` [ai⁵⁵liɛ²¹] 再/又；`jefbox` [ʨe³⁵po⁵⁵] 续（义译，对记音「打岔」）；`taf` 不
- **对音提示**：爱/再/续/不 为近义意译；"情缘"土家语无专词，以"爱"承载，需传承人确认。

**17. 回不到我们的从前** `Sunxkox taf, anf wanxtianr`
- `sunxkox` [sũ⁵⁵kʰo⁵⁵] 回（例 p32/p62）；`taf` [ta³⁵] 不；`anf` [ã³⁵] 我们（T词典「我们 anf」，对记音「伢你」）；`wanxtianr` [wã⁵⁵tʰiã²¹] 从前（T词典「从前 wanvtian」，对记音「哎时节」）
- 记音对音：松阔(回) / 它提(不到?) / 伢你(我们) / 捏哎时节(从前)——逐一对应。
