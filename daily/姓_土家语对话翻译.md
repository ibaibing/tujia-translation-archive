> 传承人口音优先，词典标准形并列于解析层
> 「田」= tian（借汉姓氏读法，传承人确认）
> 「什么/哪个」= nei（疑问句中；传承人口音写作 nei，IPA 记为 **niɛ⁵⁵**——传承人口音证据。需注意：词典 p371〔ʨʰiɛ⁵³〕〈代〉「什么」例句中出现的 ~ 是本词条自代符（代表 ʨʰiɛ⁵³ 本身），**并非独立 niɛ⁵⁵**；且词典独立词头〔niɛ⁵⁵〕只有「二/天/日子/的和」等义，无「什么」义。故 niɛ⁵⁵ 作为「什么」是传承人口音的弱化缩略。Ye 拼音为「什么」的同义词项有多个，B词典 收录：**laxxir**〔laixxir, leixxir, ngeixxir, **laix**〕、**qiev**〔**qiex**qier, qiexxier, qir, qirqiex, qirqiexxir〕、keifdix、senxmor——**传承老师确认 laix（=laxxir）与 qiex（=qiev 异体）为并列说法，因地而异，同义**，本对话取 **qiex**〔nif qiex jiaxkax〕、亦可作 **laix**〔nif laix jiaxkax〕，二者均可。⚠️ 注意：`laix` 是 B词典收录的方言词形，**S词典未收录**，故不标 IPA；`qiev/qiex` 对应S词典 ʨʰiɛ⁵³，但 `laix` 与 ʨʰiɛ⁵³ 音位并不对应，**不能相互充抵**）
> 「也」= bai / nai / dai（= 词典 pɤ⁵⁵〈副〉的方言变体；Ye 标准形 = **bef**（p = 清不送气 = Ye 的 b 音，非浊化变体）。传承人口音听辨形 bai/nai/dai 为口语层的前接高元音音变）
> 「贵」= 非省略，即疑问代词「什么/哪个」本身（传承老师：laix / qiex 都可说，意思一样）——汉语「您贵姓」实等于「你 什么 姓」，土家语用 laix 或 qiex 承担「贵/什么」的疑问功能
> 「是的」= so（传承人单音节，对应词典 sou²¹，非 sou²¹ ta³⁵ 复合）

## 第二层：解析（词典依据 + 传承人口音对照）

### 标题：天天学习土家语

- **天天 / 每天** = `la⁵⁵ niɛ⁵⁵ xɤ⁵⁵` + 尾音节。词典两条例证：
  - p51「你**天天**看的那个电视剧」= `la⁵⁵niɛ⁵⁵xɤ⁵⁵xɤ⁵⁵`（尾叠 `xɤ⁵⁵xɤ⁵⁵`，强调「每一天」）；Ye = **laxniexhoxhox**
  - p29「她**每天**都没事（干）」= `la⁵⁵niɛ⁵⁵xɤ⁵⁵ liɛ²¹`（尾 `liɛ²¹`）；Ye = **lax niex hox lier**
  - 传承人口音 `lax niex hix lier` 即「每天」读法（`xɤ⁵⁵` 口音近 `hi⁵⁵`）。两种表达同源，均成立
- **学习** = a³⁵ɣɨ⁵⁵（S词典 p28）；Ye = **afhxix**（B词典 afhxix，(afyix)，to study）
- **土家语** = pi³⁵ʦɿ⁵⁵sa²¹（S词典 p218 词条 [pi³⁵ʦɿ⁵⁵sa²¹]〈名〉「土话，土家语」；p229 例：我父亲能说土家语 = pi³⁵ʦɿ⁵⁵sa²¹ lii³⁵）；Ye = **bifzixsar**（Ye 对 IPA 声母的正常转写：p = 清不送气塞音 = 汉语拼音 b；pʰ = 清送气 = 汉语拼音 p）
- **语序更正（重要）**：本句为「学·土家语」，土家语是宾语、学习是动词，按 SOV **宾语必须前置**——正确顺序为 **天天 · 土家语 · 学习** = `lax niex hix lier bifzixsar afhxix`。初版误写为「天天 · 学习 · 土家语」（SVO），已按传承人口音纠正。

### 幕名：《姓》

- **姓** = ʨia⁵⁵kʰa⁵⁵（S词典 p346：「〔ʨia⁵⁵kʰa⁵⁵〕〈动〉姓，以……为姓：ŋa³⁵lu⁵³～，pʰũ²¹～sou²¹ta³⁵. 我姓鲁，不是姓彭」）；Ye = **jiaxkax**（B词典 jiaxkax=surname，kar=to be surnamed）
- 传承人口音：jiaka / jaika
- **更正说明**：初版误写为 `xɿ³⁵`，实为 ʨia⁵⁵kʰa⁵⁵，本次按传承人纠正

### 甲：您贵姓

- 传承人口音：**ni nei jaika**（nei 的 IPA = **niɛ⁵⁵**，传承人口音）
- 拆词：ni（你）+ **nei / niɛ⁵⁵（什么，疑问代词，口语音）** + jaika（姓 = ʨia⁵⁵kʰa⁵⁵）
- 词典依据：
  - 你 = ni³⁵（p146），Ye = nif
  - 姓 = ʨia⁵⁵kʰa⁵⁵（p346），Ye = jiaxkax / kar（surnamed）
  - **什么 = ʨʰiɛ⁵³**（p371，疑问代词）；Ye 同义词项：**qiex**〔=qiev 异体〕、**laix**〔=laxxir 异体〕、keifdix、senxmor
  - **哪个 = a²¹sɤ⁵³**（p24，同 a⁵⁵sɤ²¹）/ T词典 kʰi²¹ti⁵⁵；B词典 keifdix / keif
  - 传承人 **nei（niɛ⁵⁵）** = 上述"什么/哪个"的口语弱化缩略（声母 ʨʰ→n 弱化、韵母 iɛ→i、调值合并）。⚠️ 注意：词典 p371「什么」例句中的 ~ 是词条自代符（指 ʨʰiɛ⁵³ 本身），并非独立 niɛ⁵⁵；词典〔niɛ⁵⁵〕独立词头只有"二/天/日子/的和"等义。故 niɛ⁵⁵ 仅能作传承人口音证据，Ye 拼音取规则形 **qiex**
- **「什么」双说法（传承老师确认，重要）**：老师指出此处 **laix** 与 **qiex** 都可以说，"地方不同说法不同，意思一样"。B词典印证：`laxxir〔laixxir, leixxir, ngeixxir, laix〕pron. what` 与 `qiev〔qiexqier, qiexxier, qir, qirqiex, qirqiexxir〕pron. what` 是并列的疑问代词，`laix` 是 laxxir 的口语简写、`qiex` 是 qiev 的口语简写。故本句 Ye 可作 **nif qiex jiaxkax** 或 **nif laix jiaxkax**，二者同义。
- **关于「贵」的更正**：初版误将"贵"标为「省略，土家语无对应词」。老师指出"贵"就是疑问代词"什么/哪个"本身——汉语"您贵姓"实等于"你 什么 姓"，土家语用 laix 或 qiex 承担"贵/什么"的疑问功能，**并非省略**。
- 说明：整个句子为"你 什么 姓"（SOV），疑代词置于动词前。

### 乙：我姓田

- 传承人口音：**nga tianjiaka**
- 拆词：nga（我）+ tian（田，借汉姓氏读法）+ jiaka（姓）
- 词典依据：
  - 我 = ŋa³⁵（p144），Ye = ngaf
  - 姓 = ʨia⁵⁵kʰa⁵⁵（p346），Ye = jiaxkax
  - 田（姓氏）= **tianr**（B词典 tianr「(surname)」）；借汉姓氏读法范例：S词典 p50 例「没有姓洪的」= pʰũ²¹xũ⁵⁵（"洪"借汉音 xũ⁵⁵）
- **更正说明**：初版误写为 `thia³⁵`，传承人口音为 `tian`（借汉姓氏直接以汉语音 tian 记写，与"种田"无关），Ye = tianr

### 甲：我也姓田

- 传承人口音：**nga bai tianjiaka**（"也"发音听辨为 bai/nai/dai，Ye = bef/yex）
- 拆词：nga（我）+ **bai（也，= pɤ⁵⁵ 方言变体）** + tian（田）+ jiaka（姓）
- 词典依据：
  - **也 = pɤ⁵⁵**（S词典 p229：「〔pɤ⁵⁵〕〈副〉也。①表示同样：mɤ³⁵ su²¹ liau²¹，mɤ³⁵ ~ ʦɿ²¹ tau³⁵ 天亮了，雨也没下了｜kai³⁵ sɿ²¹ ʨʰiɛ²¹ sɿ⁵⁵ li⁵⁵ pʰi⁵⁵ ɕi²¹，su³⁵ ~ lũɪ⁵³ ɕi²¹. 这水田可以种稻子，也可以养鱼。②单用或重复使用，强调两事并列：ã³⁵ a²¹ pa⁵⁵ pi³⁵ ʦɿ⁵⁵ sa²¹ lii³⁵ ɕi²¹，pʰa⁵³ sa²¹ ~ lii³⁵ ɕi²¹ 我父亲能说土家语，也能说汉语。」）；Ye = **bef / yex**（B词典「也」= bef / yex，advm also）
  - 传承人口音 **bai / nai / dai**（三写并存）= pɤ⁵⁵ 的方言变体：前接高元音 i 时发生腭化/清浊转换——pʰɤ⁵⁵ → **bai**（pʰ→b 浊化）、pɤ⁵⁵ → **nai**（p→n 鼻化）、pɤ⁵⁵ → **dai**（p→d 齿龈浊化）
- **重要更正**：初版把此处"也"写作 nei，误以为 nei 兼具"什么"与"也"两义。实际上：
  - **nei** 仅出现在疑问句中（"您贵姓"、"你属什么"），是 ʨʰiɛ⁵³ / a²¹sɤ⁵³ 的口语缩略（疑问代词"什么/哪个"），Ye = qiev
  - **bai / nai / dai** 出现在"我也姓田"这类陈述句中，是 pɤ⁵⁵〈副〉"也"的方言变体（副词"也"），Ye = bef/yex
  - 两者在传承人口音中不同词形，功能分工明确
- 说明：本句结构为"我 也 姓 田"（S 副 动 O），SOV 且动词收尾。词典例句「你不去我也不去」= tʰua²¹ ~ ti⁵³ 也印证 pɤ⁵⁵ 副词可置于主语后、动词前。Ye 整句 = **ngaf bef tianr jiaxkax**

### 乙：你属什么

- 传承人口音：**ni nei zo**（nei 的 IPA = **niɛ⁵⁵**）
- 拆词：ni（你）+ **nei / niɛ⁵⁵（什么，疑问代词）** + zo（属）
- 词典依据：
  - 属 = ʦu⁵⁵（S词典 p396：「〔ʦu⁵⁵〕〈动〉属，用十二属相记生年：ã³⁵a²¹kʰo⁵⁵ʦu⁵⁵. 我哥哥属猪」）
  - 什么 = ʨʰiɛ⁵³（S词典 p371，疑问代词）；Ye = **qiev**。⚠️ 注意：p371 例句「ni³⁵ ~ ni⁵⁵？你找什么」中的 ~ 是词条自代符（指 ʨʰiɛ⁵³ 本身），**并非独立 niɛ⁵⁵**（词典〔niɛ⁵⁵〕只有"二/天/日子/的和"等义）；niɛ⁵⁵ 作"什么"仅为传承人口音的弱化缩略（声母 ʨʰ→n、韵母 iɛ→ɛ、声调 53→55），与"您贵姓"中 nei 同词项
  - 哪个 = a²¹sɤ⁵³（S词典 p24）/ T词典 kʰi²¹ti⁵⁵
  - 传承人 **nei（niɛ⁵⁵）** 是 ʨʰiɛ⁵³ 的口语缩略（同义词项合流形；声母 ʨʰ→n、韵母 iɛ⁵³→ɛ⁵⁵、声调 53→55），与"您贵姓"中 nei 同词项
- 说明：结构为"你 什么 属"（SOV），nei（IPA **niɛ⁵⁵**）在此承担疑问代词功能（词典 ʨʰiɛ⁵³ p371 的口语缩略形），意为"什么/哪个"。与"您贵姓 = 你 什么 姓"结构完全平行。
- 整句 Ye = **nif qiev zux**（ni=nif、什么=qiev、属=zux〔按规则转写，B词典 无"属"专词〕）

### 甲：我属猴

- 传承人口音：**nga se zo**
- 拆词：nga（我）+ se（猴）+ zo（属）
- 词典依据：
  - 猴（只用于属相）= sɤ⁵⁵（S词典 p285：「〔sɤ⁵⁵〕〈名〉猴（只用于属相）」）
  - 传承人拼写 se ≈ sɤ⁵⁵（口语音 e ≈ ɤ）
  - 属 = ʦu⁵⁵（p396），传承人简写 zo
- 整句 Ye = **ngaf sex zux**（nga=ngaf、se→sex〔sɤ⁵⁵〕、属=zux〔按规则转写〕）
- **更正说明**：初版正确取 sɤ⁵⁵，传承人拼写为 se（同音异写），本对话按传承人口音保留 se。

### 乙：那你要叫我姐姐

- 传承人口音：**ngi ni nga ada jieduo**
- 拆词：ngi（那）+ ni（你）+ nga（我）+ **ada = a³⁵ta⁵³**（姐姐，口语连读）+ **jie（叫 = ʨiɛ²¹）+ duo（要 = to²¹）**
- 词典依据：
  - 那 = ai⁵⁵（S词典 p29，本对话传承人用 ngi，为方言变体/口语形）
  - **姐姐 = a³⁵ta⁵³**（S词典 p27：「〔a³⁵ta⁵³〕〈名〉姐姐」）；传承人口音 **ada** 是 a³⁵ta⁵³ 的连读缩略（首音节 a 弱读，ta⁵³→da 音变），并非独立新增词
  - **叫/喊 = ʨiɛ²¹**（S词典 p352：「〔ʨiɛ²¹〕〈动〉（将来时，ʨiɛɪ³⁵）喊。①呼唤：wo⁵³tʰa²¹ lo⁵³ ni³⁵ ~ la²¹. 外面有人喊你。③叫，（名称）是：ni³⁵ ʨʰiɛ⁵³ mi²¹ʦɿ³⁵ ~ la²¹？ 你喊什么名字？」）
  - **要/应该 = to²¹**（S词典 p311：「〔to²¹〕〈动〉……⑤应该：**ni³⁵ tʰɿ⁵³ niɛ²¹，ŋa³⁵ ni⁵⁵ a³⁵ta⁵⁵ ʨiɛ²¹ ~. 你大些，我要叫你姐姐**｜lau³⁵ʦɿ⁵⁵ tʰɿ⁵⁵ tʰuɿ⁵⁵，lai⁵³ la²¹ tʰiɛ³⁵ ʦau⁵³ liɛ²¹ niɛ³⁵ po⁵⁵ ~. 明天要去上学，今晚要早（点儿）睡觉」）—— p311 例句整句「我要叫你姐姐」= a³⁵ta⁵⁵（姐姐）ʨiɛ²¹（叫）to²¹（要），与本对话句结构**完全平行**！
  - 佐证二：**情 [ʨʰi²¹] p375** 例句⑤「欠他的情我肯定**要还**」= kʰẽ⁵³tẽ³⁵ tʰo⁵⁵ **to⁵⁵**；**还 [tʰo⁵⁵] p334** 例句「借别人的东西**要还**」= ~ **to⁵⁵**、「别人给你做的情你要记得还」= ~ **to⁵⁵** —— "要"作需要/意愿助动词，紧附动词后，音 to⁵⁵ / to²¹
- 整句 Ye = **aix nif ngaf afdav jier・to**（那 ngi → 词典标准形 ai⁵⁵ → aix；姐姐 a³⁵ta⁵³ → afdav〔B词典 afdax / darjiex〕；叫 ʨiɛ²¹ → jier〔B词典 jier=to shout, call〕；要 to²¹ → tor〔Ye 21→r〕；口音连读 jie+duo）
- **重要更正**：
  - 初版误把 **ada** 解读为"要叫"（复合动词），实际上 ada 就是 a³⁵ta⁵³（姐姐）的连读形式，与S词典 p27 一致，非新增词
  - 初版误把 **jieduo** 解读为"姐姐"，后又误判为"叫 + -tu 方言变体"；经确认，**duo = to²¹（要）**，jieduo 实为「叫（ʨiɛ²¹）+ 要（to²¹）」，S词典 p311 例句「我要叫你姐姐」= a³⁵ta⁵⁵ ʨiɛ²¹ to²¹ 为其权威依据（另见 p375/p334"要还"= tʰo⁵⁵ to⁵⁵）；-tu 启示（呼唤义后缀）予撤销
  - 本句结构：那 + 你 + 我 + 姐姐（呼语）+ 叫 + 要，SOV 且动词收尾，"要"以助动词 to²¹ 落在句尾
- **重要发现**：那 ngi 为方言变体；ada（=a³⁵ta⁵³ 连读）与 jie（=叫 ʨiɛ²¹）、duo（=要 to²¹）均可对应词典标准形，非新增词。本句正好复现S词典 p311 的现成例句结构，可用作"SOV + 助动词 to²¹（要）落句尾"的直接模板。

### 甲：你属羊?

- 传承人口音：**ni zuo zu**
- 拆词：ni（你）+ zuo（羊）+ zu（属）
- 词典依据：
  - 羊 = zo³⁵（S词典 p481：「〔zo³⁵〕〈名〉羊，指山羊」）
  - 属 = ʦu⁵⁵（p396）
  - 传承人拼写 **zuo**（羊）≈ zo³⁵（口语音，同 se 之 e≈ɤ；B词典 羊 = rof）
  - 传承人拼写 **zu**（属）≈ ʦu⁵⁵（zu/ʦu 同音位）
- 说明：疑问句末未加 liɛ²¹，传承人靠语调承担疑问。
- 整句 Ye = **nif zof zux**（ni=nif、羊 zuo→zof〔zo³⁵〕、属=zux〔按规则转写〕）

### 乙：是的

- 传承人口音：**so**
- 词典依据：
  - 是 = sou²¹（S词典 p27/29 例：「我要的是那个，不是这个 = sou²¹ ta³⁵」）
  - 传承人单音节 so（对应 sou²¹），省略了 ta³⁵ 语气词
- 整句 Ye = **so（sour）**（sou²¹ → sour〔r=21〕；B词典 souf「是」）
- **更正说明**：初版误写为 `sou²¹ ta³⁵`（复合），传承人实际只用 so 单音节应答。

## 待传承人进一步确认的音

1. **pɤ⁵⁵〈副〉"也"的三变体书面规范**：传承人口音中"也"有三种写法 bai / nai / dai——按音变推论分别是 pʰɤ⁵⁵（送气清）→ bai（浊化 b）、pɤ⁵⁵（普通清）→ nai（鼻化 n）、pɤ⁵⁵（普通清）→ dai（齿龈浊化 d）。是否需要约定统一书写形（如全记为 pɤ⁵⁵），或按传承人口音实际发音选其一？三种变体是否为方言点差异，还是同一说话人语流中的自由变体？
2. **pɤ⁵⁵ 变体规律的可推广性**：本对话中"我也姓田"的"也"因前接主语高元音 ʨi 触发音变（a-i 连读后触发后字 pʰ 浊化）。同类规律是否适用于其他前接高元音的 pɤ⁵⁵ 用例？（例如：a⁵⁵ pɤ⁵⁵ → a⁵⁵bɤ⁵⁵ 或 a⁵⁵baɤ⁵⁵ 之类的连读缩略是否也见传承人口音？）
3. **nei（IPA niɛ⁵⁵）= 什么/哪个 的归属**：nei 只出现在疑问句中（"您贵姓"、"你属什么"），IPA 为 **niɛ⁵⁵**，是S词典〔ʨʰiɛ⁵³〕〈代〉什么（p371）与〔a²¹sɤ⁵³〕〈代〉哪个（p24）的传承人口音弱化缩略。⚠️ 注意 p371 例句「ni³⁵ ~ ni⁵⁵？你找什么」中的 ~ 是词条自代符，**非独立 niɛ⁵⁵**（词典〔niɛ⁵⁵〕只有"二/天/日子/的和"等义）。是否需为 niɛ⁵⁵ 单独设词项？其音变规律（ʨʰ→n、韵母 iɛ→ɛ、声调 53→55）是否普遍？B词典 keifdix / keif「什么/哪个」对应关系如何？
4. **叫 + 要 = jieduo**：传承人口音 jieduo = 叫（ʨiɛ²¹，p352）+ 要（to²¹，p311）。S词典 p311〔to²¹〕⑤例句「我要叫你姐姐」= a³⁵ta⁵⁵ ʨiɛ²¹ to²¹ 与本句结构完全一致；另见 p375「情」"肯定要还"= tʰo⁵⁵ to⁵⁵、p334「还」"要还"= ~ to⁵⁵。"要"作意愿助动词紧附动词落句尾。需向传承人确认：口语 jieduo 中 -duo 是否确为 to²¹（要），及其与 to⁵⁵（要）的关系。
5. **姐姐 = ada**：ada 实为S词典 a³⁵ta⁵³（p27）的口语连读缩略，非新增词。是否需要为口语连读设定规范书写（ada 还是 a-ta 连写）？
6. **那 = ngi**：S词典 ai⁵⁵，传承人口音 ngi，是否为不同方言点差异？
7. **羊（属相）= zuo**：S词典 zo³⁵"山羊"，传承人 zuo ≈ zo³⁵，是否同音异写，或另有"羊（属相声）"独立词？
8. **是的 = so**：S词典 sou²¹，传承人单音节 so，是否为口语应答缩略（对应sou²¹ ta³⁵→so）？
9. **属 = zo/zu**：S词典 ʦu⁵⁵，传承人 zo/zu，是否 ʦu⁵⁵ 口语简写（u→o）或另有"属"义动词？
10. **田（姓氏）= tian**：借汉姓氏读法是否统一采用汉语音记写？其他姓氏（如 黄/张/王）是否遵循同一模式？
