## 第二层：解析（翻译依据）

逐条给出 IPA、逐词拆分、词典依据与语序说明。

### 标题：天天学习土家语

- **天天** = la⁵⁵niɛ⁵⁵xɤ⁵⁵xɤ⁵⁵（S词典：例句「她每天都没事」「你天天看的那电视剧就要来了」）

- **学习** = a³⁵ɣɨ⁵⁵（S词典 p28，将来时 a³⁵ɣɨɪ⁵⁵）

- **土家语** = pi³⁵ʦɿ⁵⁵sa²¹（例句「我父亲能说土家语」页229：pi³⁵ʦɿ⁵⁵sa²¹ lii³⁵）

- **整句**：la⁵⁵niɛ⁵⁵xɤ⁵⁵xɤ⁵⁵ pi³⁵ʦɿ⁵⁵sa²¹ a³⁵ɣɨ⁵⁵（天天 土家语 学习）

- 结构：时间 | 宾语 | 动词（SOV 天然成立）

### 《玩》/ 去玩

- **玩** = kɤ²¹ʦʰɿ³⁵（S词典 p91，「玩耍」）

- **玩（将来时）** = kɤ²¹ʦʰɿɪ³⁵（带的态黏附元音 ɪ，符合土家语将来时规则）

- **去玩** = po⁵⁵ + kɤ²¹ʦʰɿɪ³⁵：po⁵⁵ 为介词"给/往/到"（书页205），引导处所/目的；"去玩"= "往(哪儿)玩"，玩取将来时

- 结构：介词 po⁵⁵ + 玩·将来时（非独立动词"去"，前面的"去"正是可听出的 po⁵⁵）

### 甲：明天我们去玩呀

- **明天** = IPA ɣi²¹ni⁵⁵（S词典 p336）；口语 laodzis 为 Ye 拼写（B词典 第1314条 laofzix）——表中 IPA 列取词典 IPA，口语 laodzis 的对应 IPA 待传承人核对

- **我们** = ã³⁵（S词典 p32 / T词典 anf）

- **去玩** = pa⁵⁵ + 玩·将来时 kɤ²¹ʦʰɿɪ³⁵（pa⁵⁵ 即介词 po⁵⁵ 的**快读弱化变体**，\[po\~pa] 听感游移；S词典 po⁵⁵〈介〉=给/往，此处表"往·去"，快读时 o 央化变 a；传承人听音为「pa/ba」）——Ye 拼音 **pav**

- **整句**：ɣi²¹ni⁵⁵ ã³⁵ pa⁵⁵ kɤ²¹ʦʰɿɪ³⁵ ya（明天 我们 往 玩·将来 呀）

- 语序：传承人自然口语，未强制 SOV 倒装

### 乙：去哪里玩?

- **哪里** = kʰei²¹（S词典 p102 / kʰei³⁵）

- **去玩** = po⁵⁵ + 玩·将来时 kɤ²¹ʦʰɿɪ³⁵

- **整句**：kʰei²¹ po⁵⁵ kɤ²¹ʦʰɿɪ³⁵?（哪里 往 玩·将来?）——与传承人听音「ke po ge cei」相符

### 甲：去土家山寨

- **土家（毕兹卡）** = pi³⁵ʦɿ⁵⁵kʰa²¹

- **山寨（寨）** = lo⁵⁵jiou⁵⁵（S词典「寨子」p146）

- **到 / 往** = po⁵⁵（介词，书页205；此处引导处所）——与传承人听音「bo」相符

- **去** = ɣi³⁵（S词典例证多次出现，如 p23「大家都不敢去」xu³⁵ni⁵⁵ ɣi³⁵ kɤ⁵⁵；B词典 hxif=to go，T词典 tavhxifguf\[tʰa⁵⁵ɣi³⁵ku³⁵]=留步）——Ye 拼音 **hxif**。传承人听音为「gei / ei」即 ɣi³⁵（ɣ 在语流中弱化近 i）

- **整句**：pi³⁵ʦɿ⁵⁵kʰa²¹ lo⁵⁵jiou⁵⁵ po⁵⁵ ɣi³⁵（土家 山寨 到 去）——与传承人听音「bi zi ka lo you bo gei」**完全一致**

- 说明：此句「去」是实义动词 ɣi³⁵，与「去玩」的将来时后缀不同；「po⁵⁵ + 去」连读即"到……（地方）去"，为处所趋向结构（参照 p71「kʰei²¹ po⁵⁵ yi³⁵ ɕiɛ⁵⁵？你去哪里了？」）

### 乙：那山寨有什么好玩的吗?

- **那** = ai⁵⁵（S词典 p29）

- **什么** = ʨʰiɛ⁵³（S词典 p371）

- **好玩** = kɤ²¹ʦʰɿ³⁵ʦʰa³⁵（玩+好/精彩 的复合）

- **有** = ɕiɛ³⁵（p146 例句）

- **整句**：ai⁵⁵ lo⁵⁵jiou⁵⁵ ʨʰiɛ⁵³ kɤ²¹ʦʰɿ³⁵ʦʰa³⁵ ɕiɛ³⁵?（那 寨 什么 好玩 有?）

### 甲：那有呢

- **那** = ai⁵⁵；**有** = ɕiɛ³⁵；**呢** = liɛ²¹（S词典 p145 语气词）

- **整句**：ai⁵⁵ ɕiɛ³⁵ liɛ²¹（那 有 呢）——三音节与传承人听音「ai xie lie」**完全一致**

### 甲：山歌唱的很好听

- **山歌** = a²¹pʰo⁵⁵（T词典 apov；非 S词典 miɛ²¹ko⁵⁵=民歌词——口语取 apov）

- **唱** = ʦʰã³⁵（S词典 p411）

- **得（程度补语标记）** = ɕi²¹（S词典 p35，`V + 得 + 形容词`，如「你土家语说得好」= sa²¹ li²¹ \~ ʦʰa³⁵）——Ye 拼音 **xir**。传承人快读时 ɕi²¹ 后带 -a 过渡，听作 ɕia²¹

- **好听** = zu²¹po²¹ʦʰa³⁵（T词典 rubocaf）

- **整句**：a²¹pʰo⁵⁵ ʦʰã³⁵ ɕi²¹ zu²¹po²¹ʦʰa³⁵（山歌 唱 得 好听）——与传承人听音「a bo cang xia zu bo ca」相符

### 甲：哭嫁歌(表演)也很好看

> 结构说明：本句、前句「山歌唱得很好听」、后句「还可以学习大摆手舞」**均为甲一人连续所说，属并列/递进关系**（不是独立话轮）。
> **2026-09-09 传承人纠正 + 直译确认**——传承人纠正四个音：①哭嫁 `liɛ²¹`→`lai²¹`、②得 `ɕi²¹`→`ɕi⁵⁵`、③也 `pɤ⁵⁵`→`a⁵⁵`、④好看保持重叠 `mo⁵³pa⁵⁵mo⁵³ ʦʰa³⁵`。直译为「哭嫁哭的也**一点头，一点头的**，好看」。中间 `kʰu⁵⁵kʰu⁵⁵li⁵⁵`、`mo⁵³pa⁵⁵mo⁵³` **并非程度副词"非常"，也非并列/递进连词，而是表状态的重叠式**——`kʰu⁵⁵kʰu⁵⁵li⁵⁵`＝头一啄一啄（`kʰo⁵⁵pa⁵⁵ ʦua³⁵ li⁵⁵ ʦua³⁵ li⁵⁵`），形容哭嫁哭时头一颠一颠的样子；`mo⁵³pa⁵⁵mo⁵³ ʦʰa³⁵`＝好看重叠式（强调"很好看"）。
> 词典同构例证：点头＝`kʰo⁵⁵pa⁵⁵ʦua³⁵`（啄脑壳）、头/脑壳＝`kʰo⁵⁵pa⁵⁵`、「(头)啄下啄下，表状态」＝`kã²¹ʦɿ²¹ti²¹kã²¹ʦɿ²¹ti²¹`（形容头不时向前晃动），以及同类表状态重叠「白晃晃」`a²¹sɿ⁵⁵kʰu⁵⁵li⁵⁵`、「摇摇晃晃」`za⁵⁵za⁵⁵ma⁵⁵ma⁵⁵`。

- **哭嫁** = tʰa⁵⁵tiɛ⁵⁵**lai²¹**ʦɿ³⁵（整词，S词典 p318，动词；**第三音节传承人纠正为 `lai²¹`**，非之前误记的 `liɛ²¹`）✓

- **得/地（程度补语标记）** = ɕi⁵⁵（S词典 p35 `ɕi⁵⁵`〈助〉得，①用在行为动词后表示拼命地做某事、②用在动词/形容词后表示程度高；同前句「唱得很好听」的 `ɕi²¹` 是不同助词用法——此处 `ɕi⁵⁵` 为**程度高**的"得"，非 `ɕi²¹` 的宾语后置助词）——传承人直译的「哭的」即此

- **也** = a⁵⁵（**传承人纠正**，非之前沿用的 `pɤ⁵⁵`）——`a⁵⁵` 在本句位置为句中语气/连接成分（承接前句"山歌唱得好听"的并列意）；S词典 p229 `pɤ⁵⁵`＝也（表同样）仍为词典标准形，此处按传承人口语记录 `a⁵⁵`

- **头一啄一啄（一点头，一点头）** = kʰo⁵⁵pa⁵⁵ ʦua³⁵ li⁵⁵ ʦua³⁵ li⁵⁵——`kʰo⁵⁵pa⁵⁵`＝脑壳/头（S词典）；`ʦua³⁵`＝啄/点，③（头）微微向下一动（S词典，例「ko³⁵…kʰo⁵⁵pa⁵⁵ ʦua³⁵ li⁵⁵ ʦua³⁵ li⁵⁵ 头一啄一啄的」）；`X li⁵⁵ X li⁵⁵` 为**表状态重叠**，即传承人所说「一点头，一点头的」✅（词典同构「(头)啄下啄下」`kã²¹ʦɿ²¹ti²¹kã²¹ʦɿ²¹ti²¹`）——听音中 `kʰu⁵⁵kʰu⁵⁵li⁵⁵` 即此

- **好看** = mo⁵³ pa⁵⁵ mo⁵³ ʦʰa³⁵——传承人纠正为**重叠形式** `mo⁵³ pa⁵⁵ mo⁵³ ʦʰa³⁵`（"好看"重叠＝"很好看/真好看"），与词典 `pa⁵³ʦʰa³⁵`（好看）不同，此为传承人口语强调式

- **整句（传承人纠正版）**：tʰa⁵⁵tiɛ⁵⁵lai²¹ʦɿ³⁵ ɕi⁵⁵ a⁵⁵ kʰo⁵⁵pa⁵⁵ ʦua³⁵ li⁵⁵ ʦua³⁵ li⁵⁵ mo⁵³ pa⁵⁵ mo⁵³ ʦʰa³⁵（哭嫁·得·也·头·一啄一啄·好看重叠）＝「哭嫁哭的也一点头，一点头的，好看」——Ye：taxtiexlarzif xir koxpax a zuaf lix zuaf lix mox pavmox caf

- **传承人纠正要点**：
  » ①哭嫁第三音节 `liɛ²¹` → `lai²¹`；②"得" `ɕi²¹` → `ɕi⁵⁵`（程度高）；③"也" `pɤ⁵⁵` → `a⁵⁵`；④"好看"保持重叠 `mo⁵³ pa⁵⁵ mo⁵³ ʦʰa³⁵`
  » 完整听音（纠正后）：tʰa⁵⁵tiɛ⁵⁵lai²¹ʦɿ³⁵ ɕi⁵⁵ a⁵⁵ kʰo⁵⁵ pa⁵³ kʰu⁵⁵kʰu⁵⁵li⁵⁵, kʰu⁵⁵kʰu⁵⁵li⁵⁵ mo⁵³ pa⁵⁵ mo⁵³ ʦʰa³⁵

## 待传承人确认的音

1. **「去玩」= po⁵⁵/pa⁵⁵ + 玩·将来时** —— 已核对：介词 po⁵⁵（书页205，给/往/到）+ 玩·将来时 kɤ²¹ʦʰɿɪ³⁵。传承人口语快读时 po⁵⁵ 央化变 pa，听作 pa/ba（「明天我们去玩呀」听作 ã³⁵ pa⁵⁵）；「去哪里玩？」po⁵⁵ 音更清晰听作 po。✓
