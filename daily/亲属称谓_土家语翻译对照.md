## 传承人古式的构词规律（核心发现）

所有古式都是 **`[亲属根] + [性别后缀]`** 复合结构：

| 性别后缀 | 汉字记音 | 对应 IPA | 对应 Ye 后缀 | 意义 |
|----------|---------|----------|-------------|------|
| **女** | 阿捏 | a²¹niɛ²¹ | -nirgar | 阴性、母的（B词典 1604 "女性、母的"） |
| **男** | 阿巴 | a²¹pa²¹ | -axbax / -bax | 阳性、男性（B词典 0；S词典 p.0022 "阿巴，土家人常用乳名"） |

按此规律拆读传承人古式：

| 古式（汉字记音） | 拆解 | 含义 |
|----------------|------|------|
| 母斯阿捏 | 母斯 (母亲旧称) + 女 | 母亲之母 = 外婆 |
| 母斯阿巴 | 母斯 + 男 | 母亲之父 = 外公 |
| 捏可阿捏 | 捏可 (舅) + 女 | 舅妻 = 舅妈 |
| 提可阿巴 | 提可 (舅) + 男 | 舅舅 |
| 册捏阿捏 | 册捏 (姨) + 女 | 阿姨 |
| 册捏阿巴 | 册捏 + 男 | 姨父 |
| 巴也阿捏 | 巴也 (伯) + 女 | 伯母 |
| 巴也阿巴 | 巴也 + 男 | 伯伯 |
| 捏也阿捏 | 捏也 (婶 niɛ) + 女 | 婶婶 |
| 捏也阿巴 | 捏也 + 男 | 叔叔 |
| 尼可阿捏 | 尼可 (姑) + 女 | 姑姑 |
| 尼可阿巴 | 尼可 + 男 | 姑父 |

> 注：B词典 表中标注 `-nirgar` 为阴性后缀、`-axbax/-bax` 为阳性后缀；传承人的"阿捏/阿巴"是这层历史后缀的汉语音译。这一构词层是土家语**最古老**的亲属称谓系统，今式大量简化（只留根音）或借用汉语词。

### B词典 直接印证（重大发现）

B词典 词典里有与传承人完全一一对应的复合形式：

| B词典 词形 | B词典 释义 | 传承人对应 | 对应关系 |
|--------------|--------------|-----------|---------|
| `niexyexarniex` | 婶婶（父亲的弟弟之妻） | 捏也阿捏 = 婶婶 | **完全匹配** ✓ |
| `niexyexarbax` | 叔叔（父亲的弟弟） | 捏也阿巴 = 叔叔 | **完全匹配** ✓ |
| `nixkoxarbax` | 叔叔、舅舅 | 尼可阿巴 / 提可阿巴 | 同构型（姑/舅 + 男） |
| `marmax` | 阿姨；年轻女子 | 阿姨今式 = ma²¹ma³⁵ | **直接印证** ✓ |
| `jiufjiux` | 舅舅（母亲之兄弟） | 词典今式 ʨiou³⁵ʨiou⁵³ | 现代今式 |
| `nierniex` | 婶婶 | 传承人"今式" niɛ²¹niɛ⁵⁵ | **直接印证** ✓ |

结论：**传承人的"根 + 阿捏/阿巴"古式 = B词典 记录的土家语原始构词系统**，两个独立来源（口传 + 西方语言学记录）高度吻合。今式则是 20 世纪后期受汉语影响后的简化形式。

## 词典 vs 传承人 的分歧点

| 词 | 词典今式 | 传承人今式 | 观察 |
|----|---------|-----------|------|
| 伯伯 | pɤ³⁵pɤ⁵⁵ | `bar tsr` | 传承人为另一支方言或保留旧式 |
| 姑父 | kiɛ²¹ (今) / kʰa²¹kʰi²¹ (古) | `kar ker` ≈ 词典古式 | 传承人把词典"古式"作今用 |
| 阿姨 | ne²¹ʦʰi⁵⁵ (同"伯母") | `nier nir` ≈ 词典"婶" | 传承人支系内部合并边界不同 |
| 婶婶 | sẽ⁵³niã²¹ (新) | niɛ²¹niɛ⁵⁵ (词典古式) | 传承人把词典"旧式"作今用 |
| 叔叔 | su²¹su⁵⁵ (新) | ã⁵⁵pei⁵⁵ (词典古式) | 同上 |
| 嫂子 | ko³⁵kuei⁵⁵ | `tsar tsr` | 记音差异（可能同一词的方言变体） |

> 结论：传承人口传与词典今式并非完全一致。词典标〈新〉的今式，传承人多以旧式对应；传承人标"现"的多与词典"古式"或T词典记录一致。**做田野记录时应把传承人记音视为另一条独立证据链**，不要直接等同词典今式。

## 语用要点

- **今式合并**：阿姨 = 伯母（都读 ne²¹ʦʰi⁵⁵）；姑姑 = 舅妈（都读 ma²¹ma³⁵）——这是土家语与汉语称谓体系最显眼的差别
- **领属前缀**：所有"我的X"用 `a³⁵ + X`（例：a³⁵ma²¹ma⁵⁵ = 我妈妈，a³⁵pa²¹pu⁵⁵ = 我外婆）
- **称谓 vs 关系**：`niɛ⁵⁵` / `pa⁵³` 单用是关系词（"母亲"、"父亲"），`a²¹niɛ²¹` / `a²¹pa²¹` 加"阿"是**亲昵形式**或**性别后缀标记**（用于复合亲属名）
- **古式残存**：`a²¹pa²¹` "阿巴"至今仍是土家人常用的乳名（S词典 p.0022），说明古式后缀在亲属称谓外的日常语境仍有生命力
