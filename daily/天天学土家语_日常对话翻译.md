## 解析层（详解）

### 第1句：你明天有什么事吗？

**土家语 IPA：** [ni³⁵ lau³⁵ʦɿ⁵⁵ sa²¹ ẽ²¹ mo²¹]

**逐词拆分：**

| Ye拼音 | IPA | 中文义 |
|--------|-----|--------|
| nif | ni³⁵ | 你（T词典 p.123） |
| lau³⁵ʦɿ⁵⁵ | lau³⁵ʦɿ⁵⁵ | 明天（S词典 p.132） |
| sa²¹ | sa²¹ | 事、事情（T词典 p.144） |
| ẽ²¹ | ẽ²¹ | 有（S词典，动词"有"） |
| mo²¹ | mo²¹ | 否定词（S词典，表"没有/无"） |

**逐词直译：** 你 / 明天 / 事 / 有 / 无

**结构说明：** SOV 语序，"你"作主语前置，"明天"作时间状语，宾语"事"在动词"有/无"之前。疑问语气不加额外助词（技巧4：语气助词省略）。

**词典依据：**
- 明天 → `lau³⁵ʦɿ⁵⁵`，S词典 p.132
- 事情 → `sa²¹`，T词典部分144 p.39
- 你 → `nif` [ni³⁵]，T词典部分123 p.33
- 有/无 → `ẽ²¹` / `mo²¹`，S词典否定结构

### 第2句：没事，怎么啦？

**土家语 IPA：** [ŋa³⁵ ɕiã²¹, ʨʰi⁵³mo²¹ to²¹]

**逐词拆分：**

| Ye拼音 | IPA | 中文义 |
|--------|-----|--------|
| ŋa³⁵ | ŋa³⁵ | 我（T词典 p.157） |
| ɕiã²¹ | ɕiã²¹ | 闲、没有事情（S词典 p.40） |
| ʨʰi⁵³mo²¹ | ʨʰi⁵³mo²¹ | 怎么（S词典 p.67） |
| to²¹ | to²¹ | 怎样、如何（S词典，疑问代词） |

**逐词直译：** 我 / 闲（没事），怎么 / 怎样

**结构说明：** "没事"用形容词 `ɕiã²¹`（闲，没有事情）表达，主语 "我" 前置。"怎么啦？"用固定疑问短语 `ʨʰi⁵³mo²¹ to²¹`。

**词典依据：**
- 闲/没事 → `ɕiã²¹`，S词典 p.40："闲，没有事情（跟"mo³⁵忙"相对）"
- 怎么 → `ʨʰi⁵³mo²¹`，S词典 p.67

### 第3句：那我们一起去玩？

**土家语 IPA：** [ã³⁵ kai³⁵ ka²¹pa²¹ davha kɤ²¹ʦʰl³⁵]

**逐词拆分：**

| Ye拼音 | IPA | 中文义 |
|--------|-----|--------|
| ã³⁵ | ã³⁵ | 我们（T词典 p.157） |
| kai³⁵ | kai³⁵ | 去（S词典 p.73，动词"去"） |
| ka²¹pa²¹ | ka²¹pa²¹ | 逛街/游玩（S词典 p.73） |
| davha | ta⁵⁵xa²¹ | 一起（T词典 p.173） |
| kɤ²¹ʦʰl³⁵ | kɤ²¹ʦʰl³⁵ | 玩（S词典 p.91） |

**逐词直译：** 我们 / 去 / 逛街 + 玩

**结构说明：**
- "那"省略不译（技巧12：口语中可省略）
- 动词链："去" + "玩"连用，按时间顺序排（技巧5：动词链）
- T词典词典中 `davha` [ta⁵⁵xa²¹] = 一起（p.173）
- "玩"选用 `kɤ²¹ʦʰl³⁵`（S词典 p.91），口语常用

**词典依据：**
- 我们 → `anf` [ã³⁵]，T词典部分157 p.47
- 去 → `kai³⁵`，S词典 p.73
- 一起 → `davha` [ta⁵⁵xa²¹]，T词典部分173 p.21
- 玩 → `kɤ²¹ʦʰl³⁵`，S词典 p.91

**相关例句（T词典）：**
- S词典 p.73: `kai⁵⁵sã⁵⁵kuã³⁵` 逛街："没有事，我们一起去逛街"

### 第4句：好的，明天早上，你给我打电话。

**土家语 IPA：** [ʦʰa³⁵po⁵⁵la⁵⁵li²¹, lau³⁵ʦɿ⁵⁵xuã⁵⁵, ã³⁵to²¹ nif tiã³⁵xua⁵⁵ ʨiɛ³⁵]

**逐词拆分：**

| Ye拼音 | IPA | 中文义 |
|--------|-----|--------|
| ʦʰa³⁵po⁵⁵la⁵⁵li²¹ | ʦʰa³⁵po⁵⁵la⁵⁵li²¹ | 好得很（S词典 p.408，口语回应） |
| lau³⁵ʦɿ⁵⁵xuã⁵⁵ | lau³⁵ʦɿ⁵⁵xuã⁵⁵ | 明天早上（S词典 p.133） |
| ã³⁵to²¹ | ã³⁵ to²¹ | 我给你（我 + 给予方向标记） |
| nif | ni³⁵ | 你（T词典 p.123） |
| tiã³⁵xua⁵⁵ | tiã³⁵xua⁵⁵ | 电话（S词典 p.307） |
| ʨiɛ³⁵ | ʨiɛ³⁵ | 接（S词典 p.357） |

**逐词直译：** 好得很 / 明天早上 / 我 + 方向 / 你 / 电话 / 接

**结构说明：**
- "好的"用口语回应词 `ʦʰa³⁵po⁵⁵la⁵⁵li²¹`（S词典 p.408），例句中用于对话回应
- 时间词 "明天早上" `lau³⁵ʦɿ⁵⁵xuã⁵⁵` 前置
- "打电话"实际是"接电话"，用 `tiã³⁵xua⁵⁵ ʨiɛ³⁵`（S词典 p.357），SOV 语序：宾语"电话"在动词"接"之前
- "你给我打电话" = 我（方向标记）你电话接

**词典依据：**
- 好得很 → `ʦʰa³⁵po⁵⁵la⁵⁵li²¹`，S词典 p.408：例句"那好得很"
- 明天早上 → `lau³⁵ʦɿ⁵⁵xuã⁵⁵`，S词典 p.133
- 电话 → `tiã³⁵xua⁵⁵`，S词典 p.307
- 接 → `ʨiɛ³⁵`，S词典 p.357：例句 `tiã³⁵xua³⁵ ʨiɛ³⁵`（接电话）
